# Experimental prediction selections

`shortlist.json` contains 78 phone-compatible Prediction B selections generated on 14 November 2026 from the latest saved River Lab matched rankings (source 0.10.6-web.1). Each profile identifies its evidence date and exact installed model fingerprint. Results remain experimental; overlapping outcomes are not independent storm tests.

In compatible FlowFinder versions, open Settings → Experimental → Online prediction updates, choose Check GitHub, review the preview, then Use update. Incompatible model fingerprints are rejected. Use bundled predictions restores the bundled selection.

This file selects among installed candidates. It does not install new models, coefficients or gauges, and does not include the separate Tryweryn–Dee research models. No personal logs, credentials or research databases are published.
